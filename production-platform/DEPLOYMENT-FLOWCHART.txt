DEPLOYMENT FLOWCHART - HajjMed API
====================================

STAGE 1: BUILD DOCKER IMAGE
─────────────────────────────

$ docker build -f apps/api/Dockerfile -t hajjmed-api:latest .

Builder Stage (node:22-alpine):
├─ Install dependencies (pnpm)
├─ Compile TypeScript to JavaScript
└─ Create optimized build artifacts

Runtime Stage (fresh node:22-alpine):
├─ Copy compiled code only (no source)
├─ Install production dependencies only
├─ Add health checks
└─ Result: hajjmed-api:latest (274MB image)


STAGE 2: PUSH TO DOCKER HUB
────────────────────────────

$ docker login
$ docker tag hajjmed-api:latest amzan96/hajjmed-api:latest
$ docker push amzan96/hajjmed-api:latest

Result: Image available at Docker Hub
→ https://hub.docker.com/r/amzan96/hajjmed-api


STAGE 3: LOCAL DEPLOYMENT
──────────────────────────

$ cp .env.local.example .env
$ nano .env  (set DATABASE_URL, SUPABASE_*, JWT_*, etc)
$ docker compose up -d --pull always

Services Started:
┌─ API Container (amzan96/hajjmed-api:latest) ─┐
│ Port: 4000                                    │
│ Status: healthy (via /health/ready)           │
└──────────────────────────────────────────────┘
        ↓              ↓              ↓
    Redis       MinIO        Mailpit
   (cache)   (storage)      (email)
   :6379      :9000/:9001    :1025/:8025

Verify:
$ curl http://localhost:4000/health/ready
$ docker compose ps


STAGE 4: GITHUB ACTIONS CI/CD (OPTIONAL)
──────────────────────────────────────────

Setup:
1. GitHub repo → Settings → Secrets
2. Add DOCKER_HUB_USERNAME = amzan96
3. Add DOCKER_HUB_TOKEN = <token>
4. Push code to main/develop

Workflow (docker-build.yml):
├─ Triggered by: push to main/develop or PR
├─ Steps:
│  ├─ Setup Docker Buildx
│  ├─ Log in to Docker Hub
│  ├─ Build image (with layer caching)
│  ├─ Extract version tags
│  └─ Push to amzan96/hajjmed-api:latest
└─ Result: Image pushed automatically

Optional Remote Deployment (deploy.yml):
├─ Triggered by: docker-build.yml success
├─ Steps:
│  ├─ SSH to your server
│  ├─ Pull latest code
│  ├─ Run docker-compose up -d
│  ├─ Verify health checks
│  └─ Notify Slack
└─ Result: Auto-deployed to staging/production
